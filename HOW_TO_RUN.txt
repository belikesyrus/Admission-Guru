=====================================================
  ADMISSION GURU — How to Start the App
=====================================================

REQUIREMENTS
  - Python 3.10 or higher (already installed)
  - Internet connection for first-time package install (already done)

STEP 1 — Install dependencies (only needed once)
  Open Command Prompt / PowerShell in this folder and run:
    python -m pip install flask flask-cors bcrypt pyjwt reportlab

STEP 2 — Start the server
  Double-click start_server.py, OR run in terminal:
    python start_server.py

STEP 3 — Open the app
  Open your browser and go to:
    http://localhost:5000

STOP THE SERVER
  Press Ctrl+C in the terminal window.
